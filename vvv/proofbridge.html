Protocol

How ProofBridge
secures every transaction.

Three-layer cryptographic attestation. Every contribution, every payout — provable, immutable, auditable without intermediaries.

Stitch / Webhooks
Contribution triggers webhook

When a pool member pays via Stitch, a signed webhook fires to the ProofBridge listener. The payment amount, member ID, and pool reference are extracted and queued.

ED25519 / On-Chain
ED25519 receipt minted

The kernel signs the payment record with an ED25519 private key and mints a tamper-proof receipt on Polygon Amoy. The signature is verifiable by anyone with the public key.

Trust Model

Three layers. No single
point of failure.

ProofBridge's safety kernel is a three-layer architecture designed to survive oracle manipulation, validator collusion, and adversarial market conditions.

Layer 1 · TEE
Trusted Execution Environment

Validators execute proof verification inside hardware-isolated TEEs. Private keys never leave the enclave. Attestations are hardware-signed.

TYPE → Intel SGX / AMD SEV
KEY CUSTODY → SafeKrypte HSM
ATTESTATION → hardware-signed
Layer 2 · Bayesian
Beta-Binomial Fraud Detection

Every transaction is scored by a Beta-Binomial Bayesian model. Anomaly pressure — statistical deviation from pool baseline — triggers the circuit breaker halt phrase.

MODEL → Beta-Binomial
TRIGGER → kernel halt phrase
MONITORING → ANT Telemetry
Layer 3 · On-Chain
3-of-5 Oracle Quorum

The CircuitBreaker contract requires a 3-of-5 oracle quorum before any state-changing operation. Single oracle compromise cannot alter pool state.

CONTRACT → CircuitBreaker.sol
QUORUM → 3-of-5 threshold
NETWORK → Polygon Amoy (80002)
