   121→- **Styling**: Tailwind CSS 4 with shadcn/ui + 15+ custom CSS utilities + light theme overrides
   122→- **Database**: Prisma ORM (SQLite)
   123→- **Animations**: framer-motion with properly typed Variants
   124→- **Charts**: Custom lightweight SVG chart primitives (7 components) — NO recharts dependency in active sections
   125→- **Icons**: lucide-react
   126→- **Theming**: next-themes with dark/light/system toggle (hydration-safe)
   127→- **State**: React hooks + localStorage (pinned sections)
   128→- **Loading**: React.lazy() for on-demand section compilation
   129→- **Overlays**: Command Palette (⌘K), Notification Panel (F8), Keyboard Shortcuts (?), Scroll-to-Top

   131→- **New Components**: deployment-pipeline.tsx, activity-feed.tsx
