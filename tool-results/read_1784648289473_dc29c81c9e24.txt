   117→## Architecture
   118→- **Framework**: Next.js 16 with App Router (Turbopack)
   119→- **Language**: TypeScript 5 (0 errors in main app)
   120→- **Styling**: Tailwind CSS 4 with shadcn/ui + 15+ custom CSS utilities + light theme overrides
   121→- **Database**: Prisma ORM (SQLite)
   122→- **Animations**: framer-motion with properly typed Variants
   123→- **Charts**: Custom lightweight SVG chart primitives (7 components) — NO recharts dependency in active sections
   124→- **Icons**: lucide-react
   125→- **Theming**: next-themes with dark/light/system toggle (hydration-safe)
   126→- **State**: React hooks + localStorage (pinned sections)
   127→- **Loading**: React.lazy() for on-demand section compilation
   128→- **Overlays**: Command Palette (⌘K), Notification Panel (F8), Keyboard Shortcuts (?), Scroll-to-Top
   129→- **APIs**: /api/stats, /api/shards, /api/metrics, /api/policies, /api/merges, /api/export (CSV+JSON), /api/search, /api/proofs, /api/shadow-bridge, /api/audit, /api/timeline, /api/system
   130→- **New Components**: deployment-pipeline.tsx, activity-feed.tsx
   131→
   132→## Unresolved Issues / Risks
   133→- **Recharts still installed**: The package is in node_modules/package.json even though no active section imports it — could be removed to reduce bundle size
   134→- **Some chart simplifications**: SVG chart primitives lack recharts-level interactivity (tooltips, hover data points, responsive sizing)
   135→- **No real-time WebSocket push**: Notifications and activity feed are poll-based, not push-based
   136→- **No PDF export**: Only CSV and JSON export available
   137→- **Test coverage**: No E2E or unit tests exist
   138→- **Mock data in deployment pipeline**: Sync wave data is hardcoded; should connect to real Argo CD API
   139→- **Activity feed data is simulated**: Should connect to real event stream
