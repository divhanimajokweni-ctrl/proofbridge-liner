# Epistemic Runtime — Project Worklog

This worklog tracks the build of the **Epistemic Runtime** control-plane dashboard:
an invariant-enforced distributed DAG/CRDT system with a `.epd` Policy DSL,
self-repairing merges, MMR ancestry proofs, a Shadow Bridge (digital-twin)
dashboard, an invariant miner, and a CLI that validates `.epd` files against
domain-specific invariants.

Work Log:

- Scaffolded `/home/z/my-project/mini-services/epd-cli/` with `package.json` (name `epd-cli`, type `module`, scripts `dev`=`bun --hot index.ts`, `start`/`cli`=`bun index.ts`; ZERO runtime deps, only `bun-types` devDep), `tsconfig.json` (strict, `bun-types`), and `index.ts`.
- Implemented `index.ts` dual-mode entry:
  - CLI mode (subcommand present): `validate <file> [--state <s.json>] [--strict] [--json]`, `repair <file> --current <c.json> --proposed <p.json> [--json]`, `list-samples`, `proof <file> --index <n> [--json]`, `--help`.   - Materializes `SAMPLE_POLICIES`, `BROKEN_POLICY_SOURCE`, and two sample states to `policies/` at startup (idempotent `writeIfChanged` so `--hot` reloads don't storm).
- Discovered the shared parser/samples have 4 grammar mismatches; since `src/` is off-limits, added a `normalizeSource` shim + `restoreAliases` post-processor (heavily commented) that rewrites the in-memory source so the shared parser accepts the bundled samples: (1) `shard by <dim> {`→`shard by {`, (2) `strategy locality_preserving` (KEYWORD collision) aliased to a sentinel IDENT then restored on the AST + compiled-enforcer preview, (3) `preserves <fn>(<arg>)`→`preserves <arg>`, (4) `invariant "name"`→`invariant name` (policy names stay quoted). Line numbers preserved; forward-compatible.
- Set `grid-state-violating.json` to `frequency: 50.15` (in-bounds) + `thermal_headroom: 6` so only the SOFT invariant trips → exit 0 without `--strict`, exit 1 with `--strict` (matches the spec's soft-violation exit-code check; 50.6 would trip the hard `freq_bounds` invariant and force exit 1 always).
- Ran `bun install` (only `bun-types`); `bunx tsc --noEmit` passes clean.
- Background-process persistence gotcha: plain `nohup ... &` is reaped when the spawning Bash call ends in this sandbox. Fixed with the subshell+`setsid`+full-fd-redirect trick: `( setsid bun run dev >/tmp/epd-cli.log 2>&1 </dev/null & )` — reparents the service to init in a new session so it survives across calls. Verified persistent on port 3031.
- Verified everything:
  - `curl -s http://localhost:3031/health` → `{"ok":true,"service":"epd-cli","port":3031,"version":"1.0"}` ✓
  - CLI `validate policies/grid-frequency.epd --state policies/grid-state.json` → 3 passed, exit 0 ✓
  - CLI `validate ... --state policies/grid-state-violating.json` → 2 passed + 1 soft-violation, exit 0; with `--strict` → exit 1 ✓
  - CLI `validate policies/broken.epd` → 3 errors + 4 warnings, exit 1 ✓
  - CLI `proof --index 0/1/2`, `repair`, `list-samples`, `--help`, `--json` → all exit 0 ✓
  - HTTP `POST /run` with `{command:"validate"|"repair"|"proof"|"list-samples"}` → byte-identical stdout to CLI ✓
