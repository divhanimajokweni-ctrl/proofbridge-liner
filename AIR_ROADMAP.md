# AIR ROADMAP
## Evolutionary Horizons

### Epoch 1: Structural Declarations (AIR v1 - Deprecated)
* **Status:** Complete.
* **Capabilities:** Flat YAML registry tracking, simple validation lookups, manual documentation assertions.

### Epoch 2: Executable Rules (AIR v2 - Current Baseline)
* **Status:** Live / Active Production.
* **Capabilities:** Independent pluggable rule modules, automated ADR markdown generation, structural JSON Knowledge Graph output, rigid binary CI/CD blocking on hardcoded config failures.

### Epoch 3: The Evidence Compiler (AIR v3 - Active Target)
* **Status:** Under Integration via `AIR_RUNTIME_INTEGRATION.md`.
* **Capabilities:** Stateless multi-pass pipeline collection, decoupled Evidence IR and Inference IR abstractions, explainable fractional confidence scoring vectors, append-only replayable event log validation.

### Epoch 4: Predictive Architecture Intelligence (AIR v4 - Long-Term Horizon)
* **Status:** Conceptual Draft.
* **Capabilities:**
  * Ahead-of-time (AOT) simulation passes tracking pull-request impacts on downstream capabilities.
  * Real-time architectural drift detection tracking live telemetry performance against rule invariants.
  * Structural vendor concentration risk analysis and early alerting on expiring exit strategy safety windows.
