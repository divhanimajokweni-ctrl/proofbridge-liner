### 3 · Route Check: Capture-All `/api/(.*)` May Shadow Future Endpoints (MEDIUM)

**Diagnosis:** `vercel.json` line 48: `{ "src": "/api/(.*)", "dest": "/api/verify.js" }`
acts as a catch-all for all unmatched `/api/*` paths. Currently safe because all real
API handlers (`mint`, `stitch/webhook`, `pool-token/mint`, `pool-token/verify`,
`svix/app-portal`) have explicit entries before it. If a new `/api/foo` is added
without an explicit `vercel.json` entry, it will silently route to `verify.js` and
return a non-descriptive error.

**Fix:**
- Add a `{ "src": "/api/no-such-route", "dest": "/vvv/404.html" }` catch-all after all
  explicit API routes, and change line 48 to explicitly list known paths only (or
  add a 404 sentinel). Minimal change: add `/api/no-such-route → /vvv/404.html`
  as the last `/api/` entry ahead of the `(.*)` line.
