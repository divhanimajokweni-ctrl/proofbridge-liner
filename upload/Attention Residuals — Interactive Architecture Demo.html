One-Minute Overview

Core insight — time–depth duality: residual connections compress information across depth in a form analogous to how recurrent networks compress information across time. Transformers replaced fixed recurrence over sequence positions with attention; AttnRes applies an analogous transition to depth, replacing fixed residual accumulation with learned softmax attention.

Problem

PreNorm Depth Dilution

Standard residuals accumulate every layer output with a fixed coefficient of 1. Hidden-state magnitude grows with depth, early contributions become progressively diluted, and the network has no content-based mechanism for selectively retrieving earlier representations.

Approach

Attention Residuals

Each layer carries one learned pseudo-query and aggregates preceding layer outputs through softmax attention. The query is a learned parameter, while the attention weights remain input-dependent because the keys come from the token’s intermediate representations.

Scalable Form

Block AttnRes

Split L layers into N blocks. Use standard residual accumulation within each block and attention over block representations across blocks. Depth-wise storage and communication fall from O(Ld) to O(Nd).

The Problem: Depth Dilution in Standard Residual Connections

Residual connections provide an effective gradient highway, but they also prescribe how information is aggregated across depth: every layer output enters the residual stream with a fixed coefficient of 1. Unrolling the recurrence yields a uniformly weighted sum of preceding outputs. In PreNorm models, hidden-state magnitude grows with depth, progressively reducing the relative influence of any individual contribution.

Consequences: fixed unit weights cannot perform selective retrieval; residual magnitude grows with depth; early signals are progressively diluted. Prior work has observed that a non-trivial fraction of layers can be pruned with limited loss.

Core Idea: Full Attention Residuals

Replace fixed uniform residual weights with learned, content-dependent softmax attention. Each layer owns one learned pseudo-query w_l whose parameters are independent of the input. The resulting attention weights are nevertheless input-dependent because the keys are computed from each token’s actual intermediate representations. RMSNorm prevents representation scale from monopolizing the weights.

Block Attention Residuals: The Practical Scalable Form

Full AttnRes must store and transmit all L preceding layer outputs. Block AttnRes divides depth into N blocks. Within a block, ordinary residual connections accumulate into a partial sum. At block completion, the partial sum becomes one cached block representation. Later layers attend over all completed block representations, plus the current partial sum when applicable.

Efficient Implementation: Two-Phase Inference

Pseudo-queries are learned parameters known in advance. All S queries in a block can therefore be packed into one matrix multiplication and applied to the shared block-representation cache. Sequential layer execution is required only for the current within-block partial sum. Online softmax merges the inter-block and intra-block results exactly.

Results: Bounded Magnitudes, More Uniform Gradients, Consistent Gains

Two qualitative trends summarize the mechanism’s effect: Block AttnRes keeps output magnitudes bounded across depth, and its gradient magnitudes are substantially more uniform across depth than the baseline’s.
