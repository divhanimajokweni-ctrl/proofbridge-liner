## 1. Overview

The **Epistemic Runtime (ER)** is an evidence kernel that turns every meaningful system change into an immutable, verifiable fact. It is designed to ingest observations from any source, validate them against policies, produce cryptographic proofs, and project deterministic views.

**Kilo Cloud** is a suite of automation services that turn commands, events, labels, webhooks, and schedules into scoped work. Every action—bot command, code review, triage decision, fix attempt, security scan, webhook trigger—produces a traceable outcome.

**Integration Goal**: Make every Kilo automation action an **immutable, verifiable fact** in the Epistemic Runtime. This provides:

- **Complete audit trail** of all automation decisions.
- **Cryptographic proof** that each action was authorized and executed correctly.
- **Deterministic replay** of any automation workflow.
- **Trust scoring** for automation outcomes (e.g., confidence in fix correctness).
- **Regulatory compliance** (SOC2, ISO27001, POPIA) through tamper-evident logs.

### 3.2 Observation Collector

Each Kilo service emits observations to a **common collector**—either via:

- **HTTP API** (`POST /api/v1/observations`) with per‑service authentication.
- **Queue** (e.g., Cloudflare Queues, Kafka) for async ingestion.
- **Webhook** (for services that already use webhooks).

The collector normalizes events into a uniform `OperationalObservation` schema:

```typescript
interface OperationalObservation {
  source: 'kilo-bot' | 'code-review' | 'auto-triage' | 'auto-fix' | 'security-agent' | 'webhook-agent' | 'app-builder' | 'cloud-agent';
  timestamp: string; // ISO8601
  owner: {
    type: 'user' | 'organization';
    id: string;
  };
  action: string; // e.g., 'command', 'review_started', 'fix_created'
  payload: any;   // structured but redacted
  redacted: boolean;
  correlationId?: string; // for tracing
}
```

### 3.3 Ingestion Pipeline (AcceptancePipeline)

The Evidence Kernel exposes a gRPC or REST API that:

- **Validates** the observation against a policy (e.g., "only authenticated services may emit").
- **Redacts** any residual PII (scanned by regex or AI).
- **Canonicalizes** to JSON (RFC 8785).
- **Hashes** with SHA‑256.
- **Signs** with service‑specific key.
- **Sequences** (monotonic + vector clock).
- **Appends** to Fact Log (immutable WORM store).
- **Updates MMR** and returns a proof.

## 1. Evidence Client (`evidence_client.py`)



This lightweight HTTP client emits observations to the Epistemic Runtime collector. It runs asynchronously and never blocks the agent loop.



```python

# evidence_client.py

import aiohttp

import asyncio

import os



class EvidenceClient:

    def __init__(self, endpoint=None, token=None):

        self.endpoint = endpoint or os.getenv("EVIDENCE_ENDPOINT", "http://localhost:8080/api/v1/observations")

        self.token = token or os.getenv("EVIDENCE_TOKEN", "PLACEHOLDER")



    async def emit(self, observation):

        """Send observation to ER collector (non‑blocking)."""

        async with aiohttp.ClientSession() as session:

            headers = {

                "Authorization": f"Bearer {self.token}",

                "Content-Type": "application/json"

            }

            try:

                async with session.post(self.endpoint, json=observation, headers=headers) as resp:

                    if resp.status not in (200, 202):

                        print(f"⚠️ Evidence emission failed: {resp.status} – {await resp.text()}")

            except Exception as e:

                print(f"⚠️ Evidence emission exception: {e}")

```

## 2. Updated Orchestrator (`orchestrator_er.py`)



This is your main loop, now **emitting an observation on every iteration**. It records screenshots, code hashes, the Kimi reply, and the patch decision.



```python

# orchestrator_er.py

import os, re, asyncio, hashlib, time

from vision_agent import process_and_debug_visuals

from capture_canvas import capture_application_viewport

from evidence_client import EvidenceClient



# Configuration

TARGET_URL = "http://localhost:3000"

TARGET_FILE = "app/page.tsx"

MAX_ITERATIONS = 3

EVIDENCE_ENDPOINT = os.getenv("EVIDENCE_ENDPOINT", "http://localhost:8080/api/v1/observations")

EVIDENCE_TOKEN = os.getenv("EVIDENCE_TOKEN", "PLACEHOLDER")



def read_local_code(filepath):

    try:

        with open(filepath, "r", encoding="utf-8") as f:

            return f.read()

    except FileNotFoundError:

        print(f"❌ File not found: {filepath}")

        return ""



def write_local_code(filepath, new_code):

    with open(filepath, "w", encoding="utf-8") as f:

        f.write(new_code)

    print(f"💾 File updated: {filepath}")



def extract_code_from_markdown(text):

    pattern = r"```(?:tsx|typescript|javascript|html|css|python)?\n(.*?)\n```"

    matches = re.findall(pattern, text, re.DOTALL)

    if matches:

        return max(matches, key=len)

    return None



def hash_file(path):

    with open(path, "rb") as f:

        return hashlib.sha256(f.read()).hexdigest()



def hash_string(s):

    return hashlib.sha256(s.encode()).hexdigest()



def extract_reply(response_json):

    try:

        return response_json["choices"][0]["message"]["content"]

    except (KeyError, TypeError, IndexError):

        return None



async def run_vision_loop():

    client = EvidenceClient(EVIDENCE_ENDPOINT, EVIDENCE_TOKEN)

    print("🚀 Starting Epistemic‑enabled self‑healing loop...")



    for iteration in range(1, MAX_ITERATIONS + 1):

        print(f"\n--- 🔄 Iteration {iteration}/{MAX_ITERATIONS} ---")

        current_code = read_local_code(TARGET_FILE)

        if not current_code:

            break



        # 1. Capture screenshot

        screenshot_path = f"debug_frame_v{iteration}.png"

        await capture_application_viewport(TARGET_URL, output_path=screenshot_path)

        screenshot_hash = hash_file(screenshot_path)



        # 2. Run Kimi K3 analysis

        response_json = process_and_debug_visuals(screenshot_path, current_code)

        kimi_reply = extract_reply(response_json)

        if not kimi_reply:

            print("❌ No reply from Kimi – aborting.")

            break



        patched_code = extract_code_from_markdown(kimi_reply)

        before_hash = hash_string(current_code)

        after_hash = hash_string(patched_code) if patched_code else before_hash



        # 3. Build observation (redacted, PII‑safe)

        observation = {

            "schemaId": "vision/self-healing-iteration",

            "schemaVersion": 1,

            "producer": "SelfHealingAgent",

            "producerVersion": "1.0",

            "capabilitySet": ["automation.fix", "vision.debug"],

            "timestamp": time.time(),

            "owner": {"type": "system", "id": "vision-loop"},

            "payload": {

                "iteration": iteration,

                "screenshotHash": screenshot_hash,

                "beforeCodeHash": before_hash,

                "afterCodeHash": after_hash,

                "kimiReply": kimi_reply[:500],  # truncated to avoid bloat

                "wasPatched": patched_code is not None and patched_code.strip() != current_code.strip()

            }

        }



        # 4. Emit evidence (async, fire‑and‑forget)

        await client.emit(observation)



        # 5. Apply patch if needed

        if observation["payload"]["wasPatched"]:

            print("🛠️ Patching code...")

            write_local_code(TARGET_FILE, patched_code)

            print("⏳ Waiting 5s for HMR...")

            await asyncio.sleep(5)

        else:

            print("✅ No changes needed – convergence reached.")

            break



        # Cleanup

        if os.path.exists(screenshot_path):

            os.remove(screenshot_path)



    print("\n🏁 Loop finished.")



if __name__ == "__main__":

    asyncio.run(run_vision_loop())

    .filter(f => f.type === 'self_healing_iteration')

    .map(f => ({

      timestamp: f.acceptedAt,

      iteration: f.payload.iteration,

      beforeHash: f.payload.beforeCodeHash,

      afterHash: f.payload.afterCodeHash,

      patched: f.payload.wasPatched,

      replyHash: hash(f.payload.kimiReply),

    }))

);



registry.register('self-healing-success-rate', (facts) => {

  const total = facts.filter(f => f.type === 'self_healing_iteration');

  const patched = total.filter(f => f.payload.wasPatched);

  return {

    total: total.length,

    patched: patched.length,

    successRate: total.length > 0 ? patched.length / total.length : 0,

  };

});

```
