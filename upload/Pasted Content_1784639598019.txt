# Bridging the Gap: Aligning the Epistemic Runtime with the Hydro-Bayesian Research Architecture

---

## Executive Summary

The Epistemic Runtime and the Hydro-Bayesian Kernel represent two distinct but complementary systems. The **Hydro-Bayesian Kernel (HBK)** is the scientific model under investigation—a computational engine integrating EPANET hydraulic simulation with Bayesian filtering. The **Epistemic Runtime** is the execution and governance substrate—a deterministic, auditable execution environment that ensures every simulation trial is reproducible, verifiable, and cryptographically provable.

This document proposes a **principled integration architecture** that bridges these systems without compromising the separation between scientific research and commercial infrastructure. The integration enables the HBK to leverage the Epistemic Runtime's reproducibility guarantees while preserving the HBK's status as a publishable, open research output.

### 2.2 The Integration Interface

The HBK should interact with the Epistemic Runtime through a **well-defined, minimal API** that captures execution metadata without exposing the runtime's internals.

```typescript
// packages/hbk/src/interfaces/runtime-adapter.ts

/**
 * Minimal interface between HBK and Epistemic Runtime.
 * This is the ONLY integration point.
 */
export interface RuntimeAdapter {
  /**
   * Register a simulation trial with the runtime
   * Returns a proof record that can be verified later
   */
  registerTrial(params: TrialParams): Promise<TrialProof>;

  /**
   * Record a simulation step's outputs
   * Chain creates an immutable proof log
   */
  recordStep(params: StepParams): Promise<StepReceipt>;

  /**
   * Retrieve a previously recorded trial
   * Allows verification and replay
   */
  getTrial(trialId: string): Promise<ArchivedTrial>;
}

export interface TrialParams {
  trialId: string;
  timestamp: string;
  environment: {
    epanetVersion: string;
    networkHash: string;
    leakParameters: LeakParameters;
  };
  algorithm: {
    type: 'PF' | 'EnKF';
    populationSize: number;
    priors: any;
    prngSeed: string;
  };
  evidence: {
    observationCount: number;
    durationSeconds: number;
  };
}

export interface StepParams {
  trialId: string;
  stepIndex: number;
  state: StateSnapshot;
  evidence: EvidenceSnapshot;
  posterior: PosteriorDistribution;
  metrics: StepMetrics;
}

export interface TrialProof {
  trialId: string;
  proofHash: string;
  proofPath: string;
  chainIndex: number;
}

export interface ArchivedTrial {
  trialId: string;
  proof: TrialProof;
  steps: StepReceipt[];
  summary: TrialSummary;
}
```

### 4. Concrete Integration: HBK Executing via Runtime

#### 4.1 HBK Implementation with Runtime Integration

```typescript
// packages/hbk/src/simulation/hbk-runner.ts

import { RuntimeAdapter, TrialParams, StepParams } from '../adapters/runtime-adapter';
import { EpanetSimulator } from './epanet-simulator';
import { ParticleFilter } from '../inference/particle-filter';
import { EnsembleKalmanFilter } from '../inference/ensemble-kalman-filter';
import { ScenarioConfig, ScenarioResult } from '../scenarios/types';

export class HBKRuntimeRunner {
  private runtime: RuntimeAdapter;

  constructor(runtimeAdapter: RuntimeAdapter) {
    this.runtime = runtimeAdapter;
  }

  /**
   * Run a single trial through the Epistemic Runtime
   * All execution metadata is automatically captured and proven
   */
  async runTrial(
    scenario: ScenarioConfig,
    algorithmType: 'PF' | 'EnKF',
    prngSeed: string
  ): Promise<ScenarioResult> {
    const trialId = this.generateTrialId(scenario, algorithmType);

    // Step 1: Register trial with runtime
    const params: TrialParams = {
      trialId,
      timestamp: new Date().toISOString(),
      environment: {
        epanetVersion: this.getEpanetVersion(),
        networkHash: scenario.networkHash,
        leakParameters: scenario.leakParameters,
      },
      algorithm: {
        type: algorithmType,
        populationSize: algorithmType === 'PF' ? 750 : 64,
        priors: scenario.priors,
        prngSeed,
      },
      evidence: {
        observationCount: scenario.durationSeconds / 5, // 0.2 Hz sampling
        durationSeconds: scenario.durationSeconds,
      },
    };

    // This registers the trial and returns a proof record
    const proof = await this.runtime.registerTrial(params);

    // Step 2: Initialize simulation and filter
    const simulator = new EpanetSimulator(scenario.network);
    const filter = algorithmType === 'PF'
      ? new ParticleFilter(params.algorithm.populationSize, scenario.priors, prngSeed)
      : new EnsembleKalmanFilter(params.algorithm.populationSize, scenario.priors, prngSeed);

    // Step 3: Run simulation loop with step recording
    let currentState = await simulator.initialize();
    let stepIndex = 0;

    while (!simulator.isComplete()) {
      // Get evidence at this timestep
      const evidence = await simulator.getEvidence();

      // Run filter update
      const posterior = filter.update(currentState, evidence);

      // Record step with runtime
      const stepParams: StepParams = {
        trialId,
        stepIndex,
        state: currentState,
        evidence,
        posterior,
        metrics: {
          rmse: this.calculateRMSE(posterior, scenario.trueLeakLocation),
          brierScore: this.calculateBrierScore(posterior, scenario.trueLeakLocation),
          falsePositiveRate: this.calculateFPR(posterior, scenario.trueLeakLocation),
          latencyMs: stepMetrics.latency,
          convergenceTime: this.calculateConvergenceTime(posterior),
        },
      };

      // Record step → immutable proof log entry
      await this.runtime.recordStep(stepParams);

      // Advance simulation
      currentState = await simulator.step();
      stepIndex++;
    }

    // Step 4: Return result (which is also archived)
    return {
      trialId,
      proof,
      algorithm: algorithmType,
      finalMetrics: await this.getFinalMetrics(trialId),
      convergencePath: await this.getConvergencePath(trialId),
    };
  }
}
```

#### 4.2 Runtime Adapter Implementation

```typescript
// packages/hbk/src/adapters/runtime-adapter.ts

import { RuntimeAdapter, TrialParams, StepParams } from '../interfaces/runtime-adapter';
import { createHash } from 'crypto';

/**
 * Production implementation: Connects to the Epistemic Runtime
 */
export class EpistemicRuntimeAdapter implements RuntimeAdapter {
  private runtimeEndpoint: string;

  constructor(endpoint: string = 'http://localhost:3001/api/runtime') {
    this.runtimeEndpoint = endpoint;
  }

  async registerTrial(params: TrialParams): Promise<TrialProof> {
    const response = await fetch(`${this.runtimeEndpoint}/trials`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(params),
    });

    if (!response.ok) {
      throw new Error(`Runtime trial registration failed: ${response.status}`);
    }

    return response.json();
  }

  async recordStep(params: StepParams): Promise<StepReceipt> {
    const response = await fetch(`${this.runtimeEndpoint}/trials/${params.trialId}/steps`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(params),
    });

    if (!response.ok) {
      throw new Error(`Runtime step recording failed: ${response.status}`);
    }

    return response.json();
  }

  async getTrial(trialId: string): Promise<ArchivedTrial> {
    const response = await fetch(`${this.runtimeEndpoint}/trials/${trialId}`);
    if (!response.ok) {
      throw new Error(`Trial retrieval failed: ${response.status}`);
    }
    return response.json();
  }
}

/**
 * Mock implementation: For development and CI (no runtime required)
 */
export class MockRuntimeAdapter implements RuntimeAdapter {
  private trials: Map<string, { params: TrialParams; steps: StepParams[] }> = new Map();

  async registerTrial(params: TrialParams): Promise<TrialProof> {
    const proof: TrialProof = {
      trialId: params.trialId,
      proofHash: createHash('sha256')
        .update(JSON.stringify(params))
        .digest('hex'),
      proofPath: `mock/proof/${params.trialId}`,
      chainIndex: this.trials.size + 1,
    };

    this.trials.set(params.trialId, { params, steps: [] });
    return proof;
  }

  async recordStep(params: StepParams): Promise<StepReceipt> {
    const trial = this.trials.get(params.trialId);
    if (!trial) {
      throw new Error(`Trial ${params.trialId} not found`);
    }

    trial.steps.push(params);

    return {
      trialId: params.trialId,
      stepIndex: params.stepIndex,
      receiptHash: createHash('sha256')
        .update(JSON.stringify(params))
        .digest('hex'),
      timestamp: new Date().toISOString(),
    };
  }

  async getTrial(trialId: string): Promise<ArchivedTrial> {
    const trial = this.trials.get(trialId);
    if (!trial) {
      throw new Error(`Trial ${trialId} not found`);
    }

    return {
      trialId,
      proof: {
        trialId,
        proofHash: 'mock-hash',
        proofPath: 'mock/path',
        chainIndex: 0,
      },
      steps: trial.steps.map((s) => ({
        trialId: s.trialId,
        stepIndex: s.stepIndex,
        receiptHash: 'mock-hash',
        timestamp: new Date().toISOString(),
      })),
      summary: {
        totalSteps: trial.steps.length,
        durationSeconds: trial.params.evidence.durationSeconds,
        finalRMSE: 0,
      },
    };
  }
}
```

```typescript
  return { passed: errors.length === 0, errors, duration };
```

#### 3.1.1 Fault-Tolerant Execution Engine

**Current State**: `evaluate()` is a pure function—it either succeeds or throws.

**Gap**: A hardware fault, network timeout, or transient error causes the entire transition to fail.

**Solution**: Implement **circuit breaker patterns** at the runtime level.

```typescript
// packages/core/runtime/engine-fault-tolerant.ts

export interface FaultTolerantRuntime<State, Observation> {
  /**
   * Evaluate with automatic retry and graceful degradation
   * - Retries on transient failures (network, timeouts)
   * - Falls back to safe state on persistent failures
   * - Logs every failure for audit
   */
  evaluateWithResilience(
    state: State,
    observation: Observation,
    ruleSet: CompiledRuleSet,
    epoch: ConstitutionalEpoch,
    options: ResilienceOptions
  ): Promise<Verdict<State>>;
}

export interface ResilienceOptions {
  maxRetries: number;          // Default: 3
  retryBackoff: number;        // Exponential backoff factor
  fallbackMode: 'safe' | 'maintain' | 'report';
  timeoutMs: number;           // Per-evaluation timeout
  circuitBreakerThreshold: number; // Failures before circuit opens
}

/**
 * Implementation: Wraps evaluate() with resilience
 */
export class FaultTolerantRuntime<State, Observation>
  implements FaultTolerantRuntime<State, Observation>
{
  private runtime: StateslessRuntime<State, Observation>;
  private circuitState: 'CLOSED' | 'OPEN' | 'HALF_OPEN' = 'CLOSED';
  private consecutiveFailures = 0;

  async evaluateWithResilience(
    state: State,
    observation: Observation,
    ruleSet: CompiledRuleSet,
    epoch: ConstitutionalEpoch,
    options: ResilienceOptions = { maxRetries: 3, retryBackoff: 2, fallbackMode: 'safe', timeoutMs: 5000, circuitBreakerThreshold: 5 }
  ): Promise<Verdict<State>> {
    
    // Check circuit breaker
    if (this.circuitState === 'OPEN') {
      return this.fallbackVerdict(state, 'Circuit breaker open - system degraded');
    }

    let lastError: Error | null = null;
    let attempt = 0;

    while (attempt < options.maxRetries) {
      try {
        const result = await this.evaluateWithTimeout(
          state, observation, ruleSet, epoch, options.timeoutMs
        );

        // Success: reset circuit
        this.consecutiveFailures = 0;
        this.circuitState = 'CLOSED';
        return result;

      } catch (error) {
        lastError = error as Error;
        attempt++;
        
        // Log failure for audit
        await this.logFailure({
          timestamp: new Date().toISOString(),
          attempt,
          error: lastError.message,
          stateHash: hashObject(state),
          observationHash: hashObject(observation),
        });

        // Check if we should open circuit
        this.consecutiveFailures++;
        if (this.consecutiveFailures >= options.circuitBreakerThreshold) {
          this.circuitState = 'OPEN';
          console.error(`[Runtime] Circuit breaker OPEN after ${this.consecutiveFailures} consecutive failures`);
          break;
        }

        // Exponential backoff
        const delay = options.retryBackoff ** attempt * 100;
        await this.sleep(delay);
      }
    }

    // All retries failed
    return this.fallbackVerdict(state, `All retries failed: ${lastError?.message}`);
  }

  private async evaluateWithTimeout(
    state: State,
    observation: Observation,
    ruleSet: CompiledRuleSet,
    epoch: ConstitutionalEpoch,
    timeoutMs: number
  ): Promise<Verdict<State>> {
    return new Promise((resolve, reject) => {
      const timeout = setTimeout(() => {
        reject(new Error(`Evaluation timeout after ${timeoutMs}ms`));
      }, timeoutMs);

      try {
        const result = this.runtime.evaluate(state, observation, ruleSet, epoch, '', null);
        clearTimeout(timeout);
        resolve(result);
      } catch (error) {
        clearTimeout(timeout);
        reject(error);
      }
    });
  }

  private fallbackVerdict(state: State, reason: string): Verdict<State> {
    return {
      accepted: false,
      candidateState: state,
      proof: {
        epochId: 'fallback',
        observationHash: 'fallback',
        inferenceHash: '',
        previousProofHash: null,
        signature: '',
        timestamp: new Date().toISOString(),
        divergenceSignals: [reason],
      },
      divergenceSignals: [reason],
    };
  }

  private sleep(ms: number): Promise<void> {
    return new Promise(resolve => setTimeout(resolve, ms));
  }

  private async logFailure(failure: any): Promise<void> {
    // Append to immutable failure log
    // In production: write to distributed log
    console.warn('[Runtime] Evaluation failure:', failure);
  }
}
```

#### 3.1.2 State Recovery & Replay Protection

**Current State**: Projector folds proof log to reconstruct state. No protection against replay attacks.

**Gap**: An attacker could replay old proof logs to roll back state.

**Solution**: Add **chain height checks** and **Merkle root verification**.

```typescript
// packages/core/runtime/projector-replay-protected.ts

export interface ReplayProtectedProjector<State> extends Projector<State> {
  /**
   * Fold with replay protection
   * - Verifies chain height monotonicity
   * - Checks Merkle root integrity
   * - Prevents rollback attacks
   */
  foldWithProtection(
    genesis: Genesis,
    proofLog: readonly ProofRecord[],
    activeEpoch: ConstitutionalEpoch,
    stateTransformers: Record<string, StateTransformer<State>>,
    lastKnownHeight?: number
  ): State;
}

export class ReplayProtectedProjector<State>
  extends Projector<State>
  implements ReplayProtectedProjector<State>
{
  private merkleRootCache = new Map<string, string>();

  foldWithProtection(
    genesis: Genesis,
    proofLog: readonly ProofRecord[],
    activeEpoch: ConstitutionalEpoch,
    stateTransformers: Record<string, StateTransformer<State>>,
    lastKnownHeight?: number
  ): State {
    
    // 1. Verify chain height (prevent rollback)
    if (lastKnownHeight !== undefined && proofLog.length < lastKnownHeight) {
      throw new Error(
        `Replay attack detected: chain height decreased from ${lastKnownHeight} to ${proofLog.length}`
      );
    }

    // 2. Verify each proof's epoch validity
    const invalidEpochs: string[] = [];
    for (const proof of proofLog) {
      if (!this.isEpochValid(proof.epochId, activeEpoch)) {
        invalidEpochs.push(proof.epochId);
      }
    }
    if (invalidEpochs.length > 0) {
      throw new Error(
        `Invalid epochs in proof log: ${invalidEpochs.join(', ')}`
      );
    }

    // 3. Compute Merkle root and verify against Genesis
    const computedRoot = this.computeMerkleRoot(proofLog);
    if (genesis.rootHash && computedRoot !== genesis.rootHash) {
      throw new Error(
        `Merkle root mismatch: expected ${genesis.rootHash}, got ${computedRoot}`
      );
    }

    // 4. Proceed with normal fold
    return super.fold(genesis, proofLog, activeEpoch, stateTransformers);
  }

  private computeMerkleRoot(proofLog: readonly ProofRecord[]): string {
    if (proofLog.length === 0) return 'empty';
    
    const hashes = proofLog.map(p => p.inferenceHash);
    return merkleRoot(hashes);
  }
}
```

#### 3.2.1 Distributed Runtime Cluster

**Current State**: Single-node runtime.

**Gap**: Single point of failure for critical infrastructure.

**Solution**: Implement **distributed consensus** for runtime decisions.

```typescript
// packages/core/runtime/distributed.ts

export interface DistributedRuntime<State, Observation> {
  /**
   * Evaluate across a cluster of runtime nodes
   * - Quorum consensus on verdict
   * - Byzantine fault tolerance
   * - Automatic failover
   */
  evaluateDistributed(
    state: State,
    observation: Observation,
    ruleSet: CompiledRuleSet,
    epoch: ConstitutionalEpoch,
    quorumSize?: number
  ): Promise<DistributedVerdict<State>>;
}

export interface DistributedVerdict<State> {
  accepted: boolean;
  candidateState: State;
  proof: ProofRecord;
  consensus: {
    totalNodes: number;
    votesFor: number;
    votesAgainst: number;
    quorumReached: boolean;
  };
  nodes: {
    id: string;
    verdict: Verdict<State>;
    latency: number;
  }[];
}

/**
 * Implementation: Raft-inspired consensus
 */
export class RaftDistributedRuntime<State, Observation>
  implements DistributedRuntime<State, Observation>
{
  private nodes: RuntimeNode[] = [];
  private currentLeader: string | null = null;

  async evaluateDistributed(
    state: State,
    observation: Observation,
    ruleSet: CompiledRuleSet,
    epoch: ConstitutionalEpoch,
    quorumSize: number = Math.floor(this.nodes.length * 2 / 3) + 1
  ): Promise<DistributedVerdict<State>> {
    
    // 1. Find or elect leader
    const leader = this.getLeader();
    if (!leader) {
      throw new Error('No leader available');
    }

    // 2. Send evaluation request to all nodes
    const results = await Promise.allSettled(
      this.nodes.map(node =>
        node.evaluate(state, observation, ruleSet, epoch)
      )
    );

    // 3. Count votes
    const verdicts = results
      .filter((r): r is PromiseFulfilledResult<Verdict<State>> => 
        r.status === 'fulfilled'
      )
      .map(r => r.value);

    const votesFor = verdicts.filter(v => v.accepted).length;
    const votesAgainst = verdicts.filter(v => !v.accepted).length;

    // 4. Check quorum
    const quorumReached = votesFor >= quorumSize;

    // 5. Return consensus verdict
    const accepted = quorumReached && votesFor > votesAgainst;

    return {
      accepted,
      candidateState: accepted ? this.aggregateState(verdicts) : state,
      proof: this.aggregateProof(verdicts),
      consensus: {
        totalNodes: this.nodes.length,
        votesFor,
        votesAgainst,
        quorumReached,
      },
      nodes: verdicts.map((v, i) => ({
        id: this.nodes[i].id,
        verdict: v,
        latency: this.nodes[i].lastLatency,
      })),
    };
  }

  private aggregateState(verdicts: Verdict<State>[]): State {
    // State aggregation strategy: majority rule
    // In production: use state reconciliation
    const stateMap = new Map<string, { count: number; state: State }>();
    
    for (const v of verdicts) {
      const key = hashObject(v.candidateState);
      const existing = stateMap.get(key);
      if (existing) {
        existing.count++;
      } else {
        stateMap.set(key, { count: 1, state: v.candidateState });
      }
    }

    let maxCount = 0;
    let maxState: State | null = null;
    for (const [_, entry] of stateMap) {
      if (entry.count > maxCount) {
        maxCount = entry.count;
        maxState = entry.state;
      }
    }

    return maxState || verdicts[0].candidateState;
  }

  private aggregateProof(verdicts: Verdict<State>[]): ProofRecord {
    // Combine proofs from multiple nodes
    // In production: use threshold signatures
    return {
      epochId: verdicts[0].proof.epochId,
      observationHash: verdicts[0].proof.observationHash,
      inferenceHash: this.combinedInferenceHash(verdicts),
      previousProofHash: verdicts[0].proof.previousProofHash,
      signature: this.aggregateSignatures(verdicts),
      timestamp: new Date().toISOString(),
    };
  }

  private combinedInferenceHash(verdicts: Verdict<State>[]): string {
    // Combine all inference hashes into a single hash
    return hashObject(verdicts.map(v => v.proof.inferenceHash).sort());
  }

  private aggregateSignatures(verdicts: Verdict<State>[]): string {
    // In production: BLS signature aggregation
    return verdicts.map(v => v.proof.signature).join(':');
  }

  private getLeader(): RuntimeNode | null {
    if (this.currentLeader) {
      const leader = this.nodes.find(n => n.id === this.currentLeader);
      if (leader && leader.isHealthy()) {
        return leader;
      }
    }
    // Elect new leader
    return this.electLeader();
  }

  private electLeader(): RuntimeNode | null {
    const healthyNodes = this.nodes.filter(n => n.isHealthy());
    if (healthyNodes.length === 0) return null;
    
    // Simple leader election: oldest healthy node
    const leader = healthyNodes.reduce((a, b) => 
      a.startTime < b.startTime ? a : b
    );
    this.currentLeader = leader.id;
    return leader;
  }
}
```

#### 3.2.2 Byzantine Fault Tolerance (BFT)

**Critical for high-risk systems**: Nodes must tolerate malicious or faulty nodes.

```typescript
// packages/core/runtime/bft.ts

export interface BFTConfig {
  f: number; // Maximum Byzantine nodes
  n: number; // Total nodes (must satisfy n ≥ 3f + 1)
}

export class BFTDistributedRuntime<State, Observation>
  extends RaftDistributedRuntime<State, Observation>
{
  private config: BFTConfig;

  constructor(nodes: RuntimeNode[], config: BFTConfig) {
    super(nodes);
    this.config = config;
    
    // Verify BFT condition
    if (nodes.length < 3 * config.f + 1) {
      throw new Error(
        `BFT condition violated: need ${3 * config.f + 1} nodes, have ${nodes.length}`
      );
    }
  }

  async evaluateDistributed(
    state: State,
    observation: Observation,
    ruleSet: CompiledRuleSet,
    epoch: ConstitutionalEpoch
  ): Promise<DistributedVerdict<State>> {
    
    // 1. Send to all nodes
    const results = await Promise.allSettled(
      this.nodes.map(node =>
        node.evaluate(state, observation, ruleSet, epoch)
      )
    );

    // 2. Filter out failed nodes
    const validVerdicts = results
      .filter((r): r is PromiseFulfilledResult<Verdict<State>> => 
        r.status === 'fulfilled' && this.verifyProof(r.value.proof)
      )
      .map(r => r.value);

    // 3. BFT quorum: need at least 2f + 1 valid responses
    const required = 2 * this.config.f + 1;
    if (validVerdicts.length < required) {
      throw new Error(
        `BFT quorum not reached: need ${required}, got ${validVerdicts.length}`
      );
    }

    // 4. Byzantine agreement on verdict
    const verdictCounts = new Map<string, number>();
    for (const v of validVerdicts) {
      const key = `${v.accepted}:${hashObject(v.candidateState)}`;
      verdictCounts.set(key, (verdictCounts.get(key) || 0) + 1);
    }

    let maxCount = 0;
    let maxKey = '';
    for (const [key, count] of verdictCounts) {
      if (count > maxCount) {
        maxCount = count;
        maxKey = key;
      }
    }

    // 5. Only accept if agreement > f + 1 (Byzantine majority)
    const [accepted, stateHash] = maxKey.split(':');
    const isAgreed = maxCount > this.config.f;

    return {
      accepted: isAgreed && accepted === 'true',
      candidateState: isAgreed ? this.findStateByHash(validVerdicts, stateHash) : state,
      proof: this.aggregateProof(validVerdicts),
      consensus: {
        totalNodes: this.nodes.length,
        votesFor: validVerdicts.filter(v => v.accepted).length,
        votesAgainst: validVerdicts.filter(v => !v.accepted).length,
        quorumReached: isAgreed,
      },
      nodes: validVerdicts.map((v, i) => ({
        id: this.nodes[i].id,
        verdict: v,
        latency: this.nodes[i].lastLatency,
      })),
    };
  }

  private verifyProof(proof: ProofRecord): boolean {
    // In production: cryptographic verification
    return true;
  }

  private findStateByHash(verdicts: Verdict<State>[], hash: string): State {
    for (const v of verdicts) {
      if (hashObject(v.candidateState) === hash) {
        return v.candidateState;
      }
    }
    return verdicts[0].candidateState;
  }
}
```

```typescript
// packages/core/governance/key-rotation.ts

export interface KeyRotationPolicy {
  maxKeyAge: number;        // Seconds before rotation required
  rotationWindow: number;   // Grace period for rotation
  quorumRequired: number;   // Number of signers required
}

export class KeyRotationManager {
  private currentKey: string;
  private keyCreatedAt: number;
  private policy: KeyRotationPolicy;

  constructor(initialKey: string, policy: KeyRotationPolicy) {
    this.currentKey = initialKey;
    this.keyCreatedAt = Date.now();
    this.policy = policy;
  }

  /**
   * Check if key rotation is required
   */
  public shouldRotate(): boolean {
    const keyAge = (Date.now() - this.keyCreatedAt) / 1000;
    return keyAge > this.policy.maxKeyAge;
  }

  /**
   * Generate new key and create new epoch
   */
  public async rotateKey(
    currentEpoch: ConstitutionalEpoch,
    signers: string[]
  ): Promise<ConstitutionalEpoch> {
    if (!this.shouldRotate() && !this.isWithinRotationWindow()) {
      throw new Error('Key rotation not yet required');
    }

    // 1. Generate new key pair
    const newKey = this.generateNewKey();
    
    // 2. Get quorum signatures
    const signatures = await this.collectSignatures(newKey, signers);
    if (signatures.length < this.policy.quorumRequired) {
      throw new Error(
        `Insufficient signatures: need ${this.policy.quorumRequired}, got ${signatures.length}`
      );
    }

    // 3. Create new epoch
    return {
      id: `epoch-${Date.now()}`,
      version: `${parseInt(currentEpoch.version) + 1}`,
      parent: currentEpoch.id,
      effectiveFrom: new Date().toISOString(),
      specificationHash: currentEpoch.specificationHash,
      ruleSetHash: currentEpoch.ruleSetHash,
      signer: newKey.publicKey,
      multisigThreshold: this.policy.quorumRequired,
      signatures: signatures.map(s => s.signature),
    };
  }

  private generateNewKey(): { publicKey: string; privateKey: string } {
    // In production: use HSM or secure enclave
    return {
      publicKey: `pub-${Date.now()}`,
      privateKey: `priv-${Date.now()}`,
    };
  }

  private async collectSignatures(
    newKey: { publicKey: string; privateKey: string },
    signers: string[]
  ): Promise<{ signer: string; signature: string }[]> {
    // In production: request signatures from authorized signers
    return signers.map(s => ({
      signer: s,
      signature: `sig-${Date.now()}-${s}`,
    }));
  }

  private isWithinRotationWindow(): boolean {
    const keyAge = (Date.now() - this.keyCreatedAt) / 1000;
    return keyAge > this.policy.maxKeyAge - this.policy.rotationWindow;
  }
}
```

```typescript
// packages/core/governance/certificates.ts

export interface Certificate {
  id: string;
  subject: string;          // Entity identity
  issuer: string;           // Issuing authority
  publicKey: string;
  capabilities: string[];   // e.g., ['sign', 'validate', 'govern']
  validFrom: string;
  validUntil: string;
  revoked: boolean;
  revocationReason?: string;
  signature: string;
}

export class CertificateAuthority {
  private certificates: Map<string, Certificate> = new Map();
  private revokedList: Set<string> = new Set();

  /**
   * Issue a new certificate
   */
  public issueCertificate(
    subject: string,
    publicKey: string,
    capabilities: string[],
    validityDays: number = 365
  ): Certificate {
    const cert: Certificate = {
      id: `cert-${Date.now()}`,
      subject,
      issuer: 'VVU-CA-001',
      publicKey,
      capabilities,
      validFrom: new Date().toISOString(),
      validUntil: new Date(Date.now() + validityDays * 24 * 60 * 60 * 1000).toISOString(),
      revoked: false,
      signature: this.signCertificate(subject, publicKey, capabilities),
    };

    this.certificates.set(cert.id, cert);
    return cert;
  }

  /**
   * Verify a certificate
   */
  public verifyCertificate(cert: Certificate): boolean {
    // 1. Check revocation
    if (this.revokedList.has(cert.id)) {
      return false;
    }

    // 2. Check validity period
    const now = new Date();
    if (new Date(cert.validFrom) > now || new Date(cert.validUntil) < now) {
      return false;
    }

    // 3. Verify signature
    return this.verifySignature(cert);
  }

  /**
   * Revoke a certificate
   */
  public revokeCertificate(certId: string, reason: string): void {
    const cert = this.certificates.get(certId);
    if (!cert) {
      throw new Error(`Certificate ${certId} not found`);
    }

    cert.revoked = true;
    cert.revocationReason = reason;
    this.revokedList.add(certId);
  }
```

```typescript
// packages/core/performance/profiler.ts

export interface LatencyProfile {
  mean: number;      // ms
  p50: number;       // ms
  p95: number;       // ms
  p99: number;       // ms
  max: number;       // ms
  outliers: number;  // > 2 * p99
  samples: number;
}

export class LatencyProfiler {
  private samples: number[] = [];
  private maxSamples = 10000;

  /**
   * Record a latency measurement
   */
  public record(latencyMs: number): void {
    this.samples.push(latencyMs);
    if (this.samples.length > this.maxSamples) {
      this.samples.shift();
    }
  }

  /**
   * Get current latency profile
   */
  public getProfile(): LatencyProfile {
    const sorted = [...this.samples].sort((a, b) => a - b);
    const len = sorted.length;

    if (len === 0) {
      return { mean: 0, p50: 0, p95: 0, p99: 0, max: 0, outliers: 0, samples: 0 };
    }

    const sum = sorted.reduce((a, b) => a + b, 0);
    const p50 = sorted[Math.floor(len * 0.50)];
    const p95 = sorted[Math.floor(len * 0.95)];
    const p99 = sorted[Math.floor(len * 0.99)];
    const max = sorted[len - 1];

    const threshold = p99 * 2;
    const outliers = sorted.filter(v => v > threshold).length;

    return {
      mean: sum / len,
      p50,
      p95,
      p99,
      max,
      outliers,
      samples: len,
    };
  }

  /**
   * Check if latency meets requirements
   */
  public meetsRequirement(maxLatencyMs: number, percentile: 50 | 95 | 99 = 95): boolean {
    const profile = this.getProfile();
    const value = percentile === 50 ? profile.p50 : percentile === 95 ? profile.p95 : profile.p99;
    return value < maxLatencyMs;
  }

  /**
   * Get latency violation report
   */
  public getViolationReport(thresholdMs: number): {
    violations: number;
    totalSamples: number;
    violationRate: number;
    worstViolation: number;
  } {
    const violations = this.samples.filter(v => v > thresholdMs).length;
    const worstViolation = this.samples.reduce((max, v) => v > max ? v : max, 0);

    return {
      violations,
      totalSamples: this.samples.length,
      violationRate: violations / (this.samples.length || 1),
      worstViolation,
    };
  }

  /**
   * Reset profiler
   */
  public reset(): void {
    this.samples = [];
  }
}
```

```typescript
export interface RealTimeGuarantee {
  maxLatencyMs: number;
  percentile: 50 | 95 | 99;
  violationWindowMs: number;  // Rolling window for monitoring
  maxViolationsPerWindow: number;
}

export class RealTimeExecutor {
  private profiler: LatencyProfiler;
  private guarantee: RealTimeGuarantee;
  private violationCount: number = 0;
  private windowStart: number = Date.now();

  constructor(guarantee: RealTimeGuarantee) {
    this.guarantee = guarantee;
    this.profiler = new LatencyProfiler();
  }

  /**
   * Execute with real-time guarantee
   */
  public async execute<T>(
    operation: () => Promise<T>
  ): Promise<{ result: T; latency: number }> {
    const start = performance.now();

    try {
      const result = await operation();
      const latency = performance.now() - start;

      this.profiler.record(latency);
      this.checkViolation(latency);

      return { result, latency };
    } catch (error) {
      // Record failure as max latency
      const latency = performance.now() - start;
      this.profiler.record(latency);
      this.checkViolation(latency);
      throw error;
    }
  }

  private checkViolation(latency: number): void {
    const threshold = this.guarantee.maxLatencyMs;
    const percentile = this.guarantee.percentile;

    // Check if this sample is a violation
    const isViolation = latency > threshold;

    if (isViolation) {
      this.violationCount++;
    }

    // Check window
    const now = Date.now();
    if (now - this.windowStart > this.guarantee.violationWindowMs) {
      this.windowStart = now;

      // If too many violations, report degradation
      if (this.violationCount > this.guarantee.maxViolationsPerWindow) {
        this.reportDegradation(this.violationCount);
      }

      this.violationCount = 0;
    }
  }

  private reportDegradation(violations: number): void {
    console.error(
      `[RealTime] Degradation detected: ${violations} violations in ${this.guarantee.violationWindowMs}ms`
    );
    // In production: trigger degradation mode
  }

  /**
   * Check if current performance meets guarantee
   */
  public meetsGuarantee(): boolean {
    return this.profiler.meetsRequirement(
      this.guarantee.maxLatencyMs,
      this.guarantee.percentile
    );
  }

  public getProfile(): LatencyProfile {
    return this.profiler.getProfile();
  }
```

```typescript
  parse(dsl: string): Specification {

    return this.transformToRuntime(parsed);
  }

  validate(dsl: string): ValidationResult {
    const errors: string[] = [];
    const parsed = YAML.parse(dsl);

    // Validate syntax
    if (!parsed.specification) {
      errors.push('Missing specification root');

      for (const inv of parsed.specification.invariants) {
        if (!inv.expression) {
          errors.push(`Invariant ${inv.id} missing expression`);
        }
        if (!this.isValidExpression(inv.expression)) {
          errors.push(`Invalid expression in ${inv.id}: ${inv.expression}`);
        }
      }
    }

    return { valid: errors.length === 0, errors };
  }

  private isValidExpression(expr: string): boolean {
    // In production: use expression parser/validator
    return true;
  }

  private transformToRuntime(parsed: any): Specification {
    // Transform parsed DSL to runtime Specification
    return {
      id: parsed.specification.id,
      name: parsed.specification.name,
      version: parsed.specification.version,
      invariants: parsed.specification.invariants.map((inv: any) => ({
        id: inv.id,
```

#### 3.1.3 Specification Versioning & Lifecycle Management

**Current**: Specifications are versioned but lifecycle management is manual.

**Gap**: Production systems need automated promotion, rollback, and deprecation.

**Solution**: Implement **Specification Lifecycle Management**.

```typescript
// packages/core/governance/spec-lifecycle.ts

export enum SpecificationStatus {
  DRAFT = 'draft',
  REVIEW = 'review',
  APPROVED = 'approved',
  DEPLOYED = 'deployed',
  DEPRECATED = 'deprecated',
  ARCHIVED = 'archived',
}

export interface SpecificationVersion {
  id: string;
  spec: Specification;
  status: SpecificationStatus;
  version: string;
  createdAt: string;
  createdBy: string;
  reviewedAt?: string;
  reviewedBy?: string;
  approvedAt?: string;
  approvedBy?: string;
  deployedAt?: string;
  deployedTo?: string[];
  deprecatedAt?: string;
  deprecatedBy?: string;
  archiveAt?: string;
  auditTrail: AuditEntry[];
  riskAssessment: RiskAssessment;
  dependencies: string[];
  conflicts: string[];
}

export class SpecificationLifecycleManager {
  private versions: Map<string, SpecificationVersion> = new Map();
  private currentDeployed: string | null = null;

  /**
   * Create new specification version
   */
  public createVersion(spec: Specification, author: string): SpecificationVersion {
    const version: SpecificationVersion = {
      id: `spec-${Date.now()}`,
      spec,
      status: SpecificationStatus.DRAFT,
      version: this.nextVersion(),
      createdAt: new Date().toISOString(),
      createdBy: author,
      auditTrail: [],
      riskAssessment: this.assessRisk(spec),
      dependencies: this.findDependencies(spec),
      conflicts: this.findConflicts(spec),
    };

    this.versions.set(version.id, version);
    return version;
  }

  /**
   * Promote a specification through lifecycle stages
   */
  public promote(versionId: string, action: 'review' | 'approve' | 'deploy' | 'deprecate', actor: string): void {
    const version = this.versions.get(versionId);
    if (!version) {
      throw new Error(`Version ${versionId} not found`);
    }

    switch (action) {
      case 'review':
        version.status = SpecificationStatus.REVIEW;
        version.reviewedAt = new Date().toISOString();
        version.reviewedBy = actor;
        break;

      case 'approve':
        version.status = SpecificationStatus.APPROVED;
        version.approvedAt = new Date().toISOString();
        version.approvedBy = actor;
        break;

      case 'deploy':
        version.status = SpecificationStatus.DEPLOYED;
        version.deployedAt = new Date().toISOString();
        version.deployedTo = version.deployedTo || [];
        version.deployedTo.push('production');
        this.currentDeployed = versionId;
        break;

      case 'deprecate':
        version.status = SpecificationStatus.DEPRECATED;
        version.deprecatedAt = new Date().toISOString();
        version.deprecatedBy = actor;
        break;
    }

    version.auditTrail.push({
      action,
      actor,
      timestamp: new Date().toISOString(),
    });
  }

  /**
   * Rollback to a previous deployed version
   */
  public rollback(versionId: string): void {
    const version = this.versions.get(versionId);
    if (!version || version.status !== SpecificationStatus.DEPLOYED) {
      throw new Error(`Version ${versionId} is not deployed`);
    }

    this.currentDeployed = versionId;
    // Trigger runtime to reload specification
  }

  /**
   * Check if a specification is compatible with current deployment
   */
  public isCompatible(versionId: string): boolean {
    const version = this.versions.get(versionId);
    if (!version) return false;

    if (this.currentDeployed) {
      const current = this.versions.get(this.currentDeployed);
      if (current) {
        // Check for breaking changes
        return !this.hasBreakingChanges(current.spec, version.spec);
      }
    }

    return true;
  }

  private hasBreakingChanges(oldSpec: Specification, newSpec: Specification): boolean {
    // Check if any invariant was removed
    const oldInvariants = new Set(oldSpec.invariants.map(i => i.id));
    const newInvariants = new Set(newSpec.invariants.map(i => i.id));
    
    for (const id of oldInvariants) {
      if (!newInvariants.has(id)) {
        return true; // Invariant removed - breaking change
      }
    }

    return false;
  }

  private assessRisk(spec: Specification): RiskAssessment {
    // In production: AI-driven risk assessment
    return {
      level: 'medium',
      score: 0.5,
      factors: ['complexity', 'security-critical'],
    };
  }

  private findDependencies(spec: Specification): string[] {
    return spec.invariants
      .map(i => i.predicateKey)
      .filter(k => k.startsWith('dep_'));
  }

  private findConflicts(spec: Specification): string[] {
    // Find conflicting rules
    const conflicts: string[] = [];
    // In production: analyze rule conflicts
    return conflicts;
  }

  private nextVersion(): string {
    const versions = Array.from(this.versions.values());
    const maxVersion = versions.reduce((max, v) => {
      const num = parseInt(v.version.split('.')[0]);
      return num > max ? num : max;
    }, 0);
    return `${maxVersion + 1}.0.0`;
  }
}
```

```typescript
// packages/core/adapters/mqtt.ts
export class MQTTAdapter implements ProtocolAdapter {
  private client: MQTTClient;
  private config: MQTTConfig;

  constructor(config: MQTTConfig) {
    this.config = config;
    this.client = mqtt.connect(config.url, config.options);
  }

  async start(): Promise<void> {
    await this.client.connect();
    await this.subscribeToTopics();
  }

  async stop(): Promise<void> {
    await this.client.end();
  }

  async evaluate(state: any, observation: any): Promise<Verdict<any>> {
    // Forward evaluation to runtime via MQTT
    const response = await this.client.request('runtime/evaluate', {
      state,
      observation,
    });
    return JSON.parse(response);
  }

  subscribeEvidence(callback: (evidence: any) => void): void {
    this.client.on('evidence', callback);
  }

  async publishProof(proof: ProofRecord): Promise<void> {
    await this.client.publish('proofs', JSON.stringify(proof), { qos: 1 });
  }

  private async subscribeToTopics(): Promise<void> {
    await this.client.subscribe('runtime/+/request');
    await this.client.subscribe('evidence/+/stream');
  }
}
```

```typescript
// packages/core/formats/index.ts

export interface Serializer<T, R> {
  serialize(data: T): R;
  deserialize(data: R): T;
  contentType: string;
}

export class JSONSerializer<T> implements Serializer<T, string> {
  contentType = 'application/json';
  serialize(data: T): string { return JSON.stringify(data); }
  deserialize(data: string): T { return JSON.parse(data); }
}

export class ProtobufSerializer<T> implements Serializer<T, Uint8Array> {
  contentType = 'application/protobuf';
  constructor(private message: any) {}
  serialize(data: T): Uint8Array { return this.message.encode(data).finish(); }
  deserialize(data: Uint8Array): T { return this.message.decode(data); }
}

export class CBORSerializer<T> implements Serializer<T, Uint8Array> {
  contentType = 'application/cbor';
  serialize(data: T): Uint8Array { return CBOR.encode(data); }
  deserialize(data: Uint8Array): T { return CBOR.decode(data); }
}

export class AvroSerializer<T> implements Serializer<T, Buffer> {
  contentType = 'application/avro';
  constructor(private schema: any) {}
  serialize(data: T): Buffer { return Avro.serialize(this.schema, data); }
  deserialize(data: Buffer): T { return Avro.deserialize(this.schema, data); }
}
```

```typescript
   * Check compliance status

    partial: number;

    const planned = this.requirements.filter(r => r.status === 'planned').length;

      total,
      implemented,
      partial,
      planned,
      percentage: (implemented / total) * 100,
    };
  }

  /**
   * Get gap analysis
   */
  getGapAnalysis(): ComplianceRequirement[] {
    return this.requirements.filter(r => r.status === 'planned' || r.status === 'partial');
  }
```

```typescript
// packages/core/plugins/index.ts

export interface Plugin {
  id: string;
  name: string;
  version: string;
  author: string;
  description: string;
  capabilities: string[];

  /**
   * Initialize the plugin
   */
  init(runtime: RuntimeInterface): Promise<void>;

  /**
   * Register new predicates
   */
  registerPredicates?(): Record<string, (state?: any, obs?: any) => boolean>;

  /**
   * Register new actions
   */

  /**
   * Hook into evaluation lifecycle
   */

  afterEvaluate?(result: Verdict<any>): Promise<Verdict<any>>;

  /**
   * Hook into projection lifecycle
   */

  afterProject?(state: any): Promise<any>;

  /**
   * Cleanup
   */
  cleanup?(): Promise<void>;
}

export class PluginManager {
  private plugins: Map<string, Plugin> = new Map();

  /**
   * Load a plugin
   */
  async loadPlugin(pluginPath: string): Promise<void> {
    const plugin: Plugin = await import(pluginPath);
    await plugin.init(this.runtime);
    this.plugins.set(plugin.id, plugin);

    if (plugin.registerPredicates) {
      const predicates = plugin.registerPredicates();
      for (const [key, fn] of Object.entries(predicates)) {
        registerPredicate(key, fn);
      }
    }

    if (plugin.registerActions) {
      const actions = plugin.registerActions();
      for (const [key, fn] of Object.entries(actions)) {
        registerAction(key, fn);
      }
    }
  }

  /**
   * Get a plugin
   */
  getPlugin(id: string): Plugin | undefined {
    return this.plugins.get(id);
  }

  /**
   * List all plugins
   */
  listPlugins(): { id: string; name: string; version: string }[] {
    return Array.from(this.plugins.values()).map(p => ({
      id: p.id,
      name: p.name,
      version: p.version,
    }));
  }
}
```

## 9. Conclusion

The Epistemic Runtime is **architecturally positioned** to become the natural standard for autonomous high-risk orchestration systems. It possesses the fundamental differentiators that industry standards require:

1. **Axiom-driven design** — not inherited assumptions
2. **Industry-agnostic core** — domain knowledge is external
3. **Cryptographic verifiability** — trust is built into the architecture
4. **Constitutional governance** — policy evolves without redeployment

However, achieving industry-standard status requires **strategic evolution** across:

- **Specification** — formal DSL, industry templates, lifecycle management
- **Interoperability** — standard APIs, protocol adapters, data formats
- **Security** — certification frameworks, compliance mappings
- **Developer Experience** — SDKs, CLI, documentation, training
- **Ecosystem** — plugins, open governance, reference implementations

The roadmap outlined above provides a **practical, phased path** from a single-industry prototype to a multi-industry standard—without compromising VVU's strategic IP or competitive advantage.
